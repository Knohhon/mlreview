# Инструкции для Claude

## Проект

MLReview — open-source ассистент-критик для ML-экспериментов. Требования, критерии приёмки и этапы разработки описаны в `docs/MLReview-analysis.md` — это основной источник контекста о проекте.

## Ограничения

- **Не читать файлы диалогов.** Папка `docs/dialogs/` содержит сохранённые диалоги (переписку), а не документацию проекта. Не открывать, не искать по ним и не использовать их содержимое как контекст — ни через Read/Grep/Glob, ни через команды оболочки (`cat`, `grep`, `head` и т. п.). Исключение — только прямая просьба пользователя прочитать конкретный файл диалога.
- Новые файлы диалогов сохранять в `docs/dialogs/`, а не в корень `docs/`.
- Перемещать, переименовывать или удалять файлы в `docs/dialogs/` можно, не открывая их содержимого.
