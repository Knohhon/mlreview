# Проактивное ревью по событию «прогон завершён»

Опора: FR-R04 (проактивный анализ по событию «прогон завершён» — L1 · Must), FR-R05 (не больше 5 находок, по важности), S02 (ревью само запускается после прогона, референс — последний принятый прогон из журнала; Q8 — не позже 10 минут), FR-C03, FR-C05, X1.

Два пути: наблюдатель `mlreview watch` и вызов `mlreview.api.on_run_end` в конце скрипта обучения (`docs/specs/api.md`). Оба пишут находки в хранилище и отчёт в `.mlreview/reports/`.

## Команда

`mlreview watch --spec <путь> (--runs-dir <каталог> | --experiment <имя> [--tracking-uri <адрес>]) [--interval 60] [--once] [--limit 5] [--min-severity low]`

- Источник: подкаталоги `--runs-dir`, где есть `run.yaml`/`run.json` (признак «прогон завершён», `docs/specs/files-adapter.md`), или прогоны эксперимента MLflow со статусом `FINISHED`.
- Новый прогон — тот, которого нет в таблице прогонов хранилища. Порядок: каталоги — по имени, MLflow — по времени окончания.
- Референс — как в `on_run_end`: первый прогон последнего принятого решения; источник референса берётся из хранилища (`files:<путь>` → каталог, `mlflow:…` → id), иначе ссылка используется как есть. Если референс — сам прогон, базового нет.
- Каждые `--interval` секунд — новый просмотр; `--once` — один просмотр (для cron и CI). Ctrl+C — завершение с кодом 0.

## Ожидаемое поведение

- B1. Дано: два завершённых прогона в `--runs-dir` и рабочее пространство · когда `watch --once` · тогда оба проходят ревью, находки в хранилище, отчёты `.mlreview/reports/<run_id>.txt`; в stdout по строке «прогон <id>: находок <n> (critical <a>, high <b>) → <путь отчёта>».
- B2. Дано: повторный `watch --once` · тогда «новых завершённых прогонов нет», ревью не повторяется.
- B3. Дано: принятое решение журнала с прогоном `run-0` · тогда новый прогон сравнивается с `run-0` (в отчёте «базовый прогон: run-0»).
- B4. Дано: эксперимент MLflow с завершённым и незавершённым прогоном · тогда ревью получает только завершённый.
- B5. Дано: в отчёте больше 5 находок · тогда в файле и в выводе — 5 первых по важности и строка «скрыто: …»; в хранилище — все.
- B6. Дано: цикл наблюдения · тогда между просмотрами — пауза `--interval`; каталог без `run.yaml` (обучение идёт) пропускается до появления файла.

## Деградация и ошибки

- E1. Дано: нет рабочего пространства · тогда код 1 и подсказка `mlreview init`.
- E2. Дано: прогон с невалидным контрактом · тогда строка «прогон <id>: не проверен — <причина>», остальные прогоны проверяются; в том же процессе не повторяется.
- E3. Дано: не задан ни `--runs-dir`, ни `--experiment` (или оба) · тогда ошибка использования, код 2.
- E4. Дано: эксперимента MLflow нет · тогда код 1 «эксперимент <имя> не найден».
