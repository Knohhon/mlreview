# Актуализация документации после изменений

Опора: требование к процессу разработки (CLAUDE.md, «Порядок разработки»); NFR-09 (документация).

Реализация — `.claude/hooks/doc_sync.py`, хук `Stop` и скилл `docs-sync`.

## Ожидаемое поведение

- B1. Дано: сохранённый снимок файлов репозитория (путь → хеш содержимого) · когда файлы добавлены, изменены или удалены · тогда список изменённых путей содержит ровно их, отсортированный.
- B2. Снимок не включает `docs/dialogs/` — диалоги не считаются изменениями проекта.
- B3. Дано: markdown-файл со ссылкой на путь в обратных кавычках (путь к файлу или каталогу, в том числе с суффиксом `::имя_теста`) · когда такого файла или каталога нет и путь не игнорируется git · тогда сообщается «битая ссылка» с файлом и строкой.
- B4. Не считаются ссылками: код в блоках ```…```, токены с пробелами, URL, абсолютные пути, флаги (`--x`), шаблоны с `<`, `>`, `*`, `{`, `}`, `…`, `$`, а также токены без `/`.
- B5. Дано: идентификатор требования вида FR-‹буква›‹две цифры› или NFR-‹две цифры› в CLAUDE.md, README, `docs/specs/`, скиллах или коде `src/` · когда он не определён в таблицах `docs/MLReview-analysis.md` · тогда сообщается «неизвестное требование» с файлом и строкой.
- B6. Проверяются markdown: `CLAUDE.md`, `README.md`, `docs/**/*.md` кроме `docs/dialogs/`, `.claude/skills/**/*.md`.
- B7. Хук `Stop`: если с прошлого снимка ничего не изменилось — молчит (код 0). Если изменилось — возвращает Claude (код 2) список изменённых файлов, найденные расхождения и инструкцию: внутренние файлы Claude актуализировать самому, по остальным markdown — предупредить пользователя и предложить правки, не применяя их без согласия.
- B8. Повторный вызов в том же ходе (`stop_hook_active`) записывает текущий снимок и молчит — правки самой актуализации не вызывают новый цикл.
- B9. Первый запуск без снимка только сохраняет снимок.

## Деградация и ошибки

- E1. Нет git или repo — снимок строится по файлам на диске без учёта .gitignore; хук не падает.
- E2. Повреждённый файл снимка считается отсутствующим (как B9).

## Вне рамок

- Смысловая проверка текста (устаревшие формулировки, противоречия) — её делает Claude по инструкции хука, а не скрипт.
