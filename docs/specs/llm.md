# LLM-слой: провайдеры, сверка с фактами, гипотезы, вопросы

Опора: FR-L01 (адаптеры провайдеров, включая локальные модели; смена провайдера через конфиг — L1 · Must), FR-L02 (каждое число в ответе — из фактов анализаторов, каждое утверждение ссылается на находку — L1 · Must), FR-L03 (альтернативные объяснения — L1 · Should), FR-D07 (гипотезы со ссылками на находки и различающий эксперимент — L1 · Must), FR-R01 (`ask`), NFR-02 (независимость от провайдера), NFR-03, NFR-04 (в LLM — только агрегаты и явно выбранные примеры; аудит исходящих запросов в тестах), NFR-08 (стоимость LLM видна и пишется в журнал), Q4, Q5, S03, S05, S16, X2, X3, X6.

Пакет `mlreview.llm`. Все запросы идут через один транспорт (`mlreview.llm.transport`, стандартный `urllib`, без новых зависимостей) — его подменяют тесты и через него проходит аудит. Детерминированные находки от LLM не зависят: LLM только синтезирует гипотезы и ответы поверх них.

## Настройки

Раздел `llm` в `.mlreview/config.yaml` (`docs/specs/findings-store.md`):

| Ключ | По умолчанию | Смысл |
| --- | --- | --- |
| `provider` | `none` | `none`, `anthropic` (Messages API) или `openai` (OpenAI-совместимый Chat Completions: OpenAI, Ollama, vLLM, LM Studio) |
| `model` | `claude-opus-5-5` для `anthropic`; для `openai` обязателен | модель |
| `base_url` | `https://api.anthropic.com` / `https://api.openai.com/v1` | адрес API; локальная модель — например `http://localhost:11434/v1` |
| `api_key_env` | `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` | переменная окружения с ключом; `null` — без ключа (локальная модель) |
| `max_tokens` | 16000 | предел ответа |
| `timeout` | 300 | секунд на запрос |
| `effort` | не задан | `low`…`max` — `output_config.effort` (только `anthropic`) |
| `fallbacks` | `true` | `anthropic`: серверный запасной маршрут при отказе модели (`fallbacks: "default"`, заголовок `anthropic-beta: server-side-fallback-2026-07-01`) |
| `price` | известные модели Anthropic; локальный адрес — 0 | `{input_per_mtok, output_per_mtok}` в долларах |

Цены по умолчанию ($ за 1 млн токенов, вход / выход): `claude-opus-5-5` 4 / 20, `claude-sonnet-5-5` 2 / 10, `claude-haiku-5-5` 0,10 / 0,50, `claude-fable-5-1` 10 / 50. Для остальных моделей без `price` стоимость «неизвестна», токены показываются всегда.

## Запросы

- `anthropic`: `POST {base_url}/v1/messages`, заголовки `x-api-key`, `anthropic-version: 2023-06-01`, `content-type: application/json`; тело — `model`, `max_tokens`, `system`, `messages: [{role: user, content}]`, `output_config.format = {type: json_schema, schema}` (и `effort`, если задан), `fallbacks: "default"`. Ответ: текстовые блоки `content`, `stop_reason` (`refusal` — отказ), `usage.input_tokens`, `usage.output_tokens`, `model` (модель, которая ответила, — по ней считается цена).
- `openai`: `POST {base_url}/chat/completions`, заголовок `Authorization: Bearer <ключ>` (если ключ задан); тело — `model`, `max_tokens`, `messages: [system, user]`, `response_format: {type: json_object}`. Ответ: `choices[0].message.content`, `usage.prompt_tokens`, `usage.completion_tokens`.
- Каждый запрос пишется строкой JSON в `.mlreview/llm-log.jsonl`: время, провайдер, модель, назначение (`hypotheses`, `ask`), токены, стоимость, статус (NFR-08).

## Что уходит в LLM (NFR-04, X6)

Контекст — JSON: тип задачи, выход, сегменты, версия данных; находки — id, проверка, severity, сообщение, факты, опора, предложение; записи журнала (для `ask`). **Не уходят** доказательства (id примеров), таблицы, признаки, конфиги прогонов. Примеры уходят только явно: `--example <id>` (повторяемый) добавляет строки этих примеров (`examples` и `label`, `prediction`), и перед отправкой печатается, что именно уйдёт, с вопросом «Отправить? (да/нет)»; `--yes` — согласие заранее. Без согласия (ответ «нет» или stdin — не терминал без `--yes`) уходят только агрегаты, о чём печатается пометка. `--dry-run` печатает полный запрос и ничего не отправляет.

## Сверка ответа (FR-L02, FR-L03, X3)

Ответ — JSON по схеме. Гипотезы: `{"hypotheses": [{"id", "statement", "findings": [<id>], "alternative"}], "experiment": {"description", "findings": [<id>]}}`. Ответ на вопрос: `{"answer", "references": [<id>]}`. Сверка:

- **Числа.** Число в тексте — последовательность цифр с необязательным знаком, дробной частью (точка или запятая) и `%`; цифры внутри идентификаторов (`F-0003`, `H1`, `exp-041`, `ds-v3`) числами не считаются. Число допустимо, если оно — округление (до показанного числа знаков) модуля какого-то числа из фактов находок или ×100 от него (проценты), либо встречается в сообщениях находок, строковых фактах, записях журнала или в вопросе пользователя.
- **Ссылки.** У каждой гипотезы и у эксперимента — хотя бы одна ссылка; все ссылки — id из контекста (находки; для `ask` ещё записи журнала и прогоны).
- **Структура.** Не меньше двух гипотез, у каждой — альтернативное объяснение (FR-L03), один различающий эксперимент; ответ на вопрос — непустой с хотя бы одной ссылкой.
- Ответ, не прошедший сверку, **блокируется**: пользователь видит детерминированные находки и строку «LLM: ответ заблокирован сверкой с фактами (FR-L02): <причины>», где причина называет место нарушения: «H1: число 0.777 не найдено в фактах», «H2 без ссылки на находку», «нужно не меньше двух гипотез, получено 1».

## Команды

- `review` и `diagnose` с `--hypotheses [--focus "<текст>"]` — после детерминированного отчёта: гипотезы со ссылками на находки и различающий эксперимент (S03). `--focus` — о чём спрашивают («сегмент language=de»).
- `mlreview ask "<вопрос>" [--spec …] [--run <прогон> [--baseline <прогон>]]` — ответ по находкам хранилища, журналу (поиск — `docs/specs/journal.md`) и, если задан прогон, по его ревью (S05).
- Общие флаги LLM: `--example`, `--yes`, `--dry-run`.

## Ожидаемое поведение

- B1. Дано: `provider: anthropic` · тогда запрос — по форме выше (адрес, заголовки, тело со схемой и `fallbacks`); из ответа берутся текст, токены, модель.
- B2. Дано: `provider: openai`, `base_url: http://localhost:11434/v1`, `api_key_env: null` · тогда запрос `chat/completions` без `Authorization`, стоимость 0; смена провайдера — только правкой настроек (NFR-02).
- B3. Дано: ответ с гипотезами, где все числа из фактов и все ссылки есть · тогда `review --hypotheses` печатает гипотезы, альтернативы, эксперимент и строку «LLM: <провайдер>/<модель> · токены <вход> → <выход> · стоимость $<x>»; в JSON — поле `llm` с гипотезами, статусом `ok`, токенами и стоимостью; в `llm-log.jsonl` — строка запроса.
- B4. Дано: в ответе число, которого нет в фактах (X3), гипотеза без ссылки, ссылка на несуществующую находку, одна гипотеза или нет альтернативы · тогда ответ заблокирован с причиной; детерминированные находки на месте; код 0.
- B5. Дано: числа в виде процентов (`4.1%` от факта `0.041`), с запятой (`0,412`), со знаком минус (`−0.063` от `-0.063`), округлённые (`0.41` от `0.412345`) · тогда они допустимы; `0.43` от `0.412` — нет.
- B6. Дано: `ask "пробовал ли я focal loss?"` с записями журнала · тогда в контексте — найденные записи и связанные решения; ответ со ссылками на `H-…`/`D-…` печатается со ссылками (S05).
- B7. Дано: перехват транспорта · тогда в исходящем запросе нет id примеров, значений признаков и конфигов прогонов; с `--example te-001 --yes` — есть ровно строка этого примера (NFR-04, X6).
- B8. Дано: `--example` без `--yes` и без терминала · тогда пример не отправляется, пометка «примеры не отправлены: нет согласия (--yes)».
- B9. Дано: `--dry-run` · тогда печатается тело запроса, транспорт не вызывается.

## Деградация и ошибки

- E1. Дано: `provider: none` (по умолчанию) или нет рабочего пространства · тогда `review --hypotheses` — детерминированный отчёт и «LLM: гипотезы требуют LLM — в настройках llm.provider: none» (код 0); `ask` — код 1 и в stderr «mlreview ask: требует LLM — в настройках llm.provider: none (.mlreview/config.yaml)»; при наличии рабочего пространства в stdout — детерминированная выдача `journal search` по вопросу (S16, X2).
- E2. Дано: сеть недоступна, HTTP-ошибка, таймаут, нет переменной с ключом, ответ не JSON или отказ модели (`stop_reason: refusal`) · тогда детерминированный отчёт и «LLM: недоступен — <причина>»; для `ask` — код 1 с причиной (X2).
- E3. Дано: неверные настройки (неизвестный провайдер, `openai` без `model`, неизвестный ключ) · тогда код 1 с путём ключа.
- E4. Дано: `ask` без находок и записей журнала · тогда код 1 «нет фактов для ответа: в хранилище нет находок и записей журнала», запрос не отправляется.

## Вне рамок
