# Журнал гипотез и решений

Опора: FR-C06 (журнал гипотез и решений, связанный с прогонами — L1 · Should), FR-C04 (версия данных записи), S05 (что уже пробовал и почему отказался; поиск возвращает связанные гипотезы, прогоны и решения), S02 (референс — последний принятый прогон из журнала), S18 (вывод мог устареть после смены данных), NFR-03 (поиск детерминированный, без LLM).

Журнал хранится в той же базе рабочего пространства (`docs/specs/findings-store.md`). Записи:

| Вид | id | Поля |
| --- | --- | --- |
| гипотеза | `H-0001` | текст, прогоны, находки, статус `open` / `confirmed` / `rejected` |
| решение | `D-0001` | текст, прогоны, находки, гипотеза, исход `accept` / `reject` |
| заметка | `N-0001` | текст, прогоны, находки |

У каждой записи — время и версии данных: версии связанных прогонов из таблицы прогонов хранилища (если прогон проходил ревью) или `--data-version`.

## Команды

- `mlreview journal add hypothesis|decision|note "<текст>" [--run <id>]… [--finding <F-id>]… [--hypothesis <H-id>] [--outcome accept|reject] [--data-version <версия>]` — печатает id записи.
- `mlreview journal list [--kind …]`, `mlreview journal show <id>`.
- `mlreview journal search "<запрос>" [--spec <путь>]` — поиск; `--spec` задаёт текущую версию данных (`data.version`), иначе текущая — версия последнего прогона, прошедшего ревью.

## Ожидаемое поведение

- B1. Дано: `journal add hypothesis "focal loss поднимет recall редких классов" --run exp-017` · тогда запись `H-0001` со статусом `open` и версией данных прогона `exp-017`, если он проходил ревью.
- B2. Дано: `journal add decision "откатить focal loss" --hypothesis H-0001 --run exp-017 --outcome reject` · тогда `D-0001`; статус гипотезы — `rejected` (при `accept` — `confirmed`).
- B3. Дано: запрос «пробовал ли я focal loss?» · тогда найдены записи, где встречаются слова запроса длиной от 3 букв, кроме служебных («пробовал», «ли», «что»…); слово длиннее 5 букв сравнивается по первым 5 буквам (грубая основа для русских окончаний). Порядок — по числу совпавших слов, затем новые выше.
- B4. Дано: найдена гипотеза · тогда в выдаче — её прогоны и решения, которые на неё ссылаются (и наоборот: для решения — его гипотеза).
- B5. Дано: версия данных записи отличается от текущей · тогда пометка «данные с тех пор сменились (<было> → <стало>), вывод мог устареть».
- B6. Дано: в журнале ничего не найдено, но слова запроса есть в конфигах прогонов из хранилища · тогда «в журнале записей нет; найдено в конфигах прогонов: <id> (<ключ>=<значение>); причина решения не зафиксирована».
- B7. Дано: ничего не найдено · тогда «ничего не найдено», код 0.
- B8. Дано: решения с исходом `accept` · тогда `Store.reference_run()` — первый прогон последнего такого решения (референс проактивного ревью); без них — `None`.

## Деградация и ошибки

- E1. Дано: `--hypothesis` или `--finding` ссылается на неизвестный id · тогда код 1, «запись <id> не найдена», запись не создаётся.
- E2. Дано: `--outcome` у гипотезы или заметки, `--hypothesis` не у решения · тогда код 1 с объяснением.
- E3. Дано: пустой текст · тогда код 1.
- E4. Дано: нет рабочего пространства · тогда код 1 и подсказка `mlreview init`.
