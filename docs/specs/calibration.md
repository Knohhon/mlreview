# Калибровка и расхождение двух моделей

Опора: FR-D08 (калибровка и примеры расхождения двух моделей — L1 · Should), S02 («ECE 0,031 → 0,074 — калибровка ухудшилась»), S03 («модели расходятся на 312 примерах, 70% из них из source=forum»), NFR-05.

Модуль `mlreview.analyzers.calibration`, группа `metrics`.

## ECE

Expected calibration error, 10 корзин равной ширины на [0, 1]: ECE = Σ (nₖ/n)·|точность в корзине − средняя уверенность|. Бинарная классификация с `probabilities`: уверенность — вероятность класса 1, «точность» — доля меток 1. Multiclass с `probabilities`: уверенность — максимальная вероятность, «точность» — доля верных argmax. Интервал дельты — парный бутстрап (1000 выборок, сид 0), как в `docs/specs/run-comparison.md`.

## Проверки

| Проверка | Условие | severity |
| --- | --- | --- |
| `calibration.ece` | без базового прогона: ECE ≥ 0,1 — medium, ECE ≥ 0,05 — low | medium / low |
| `calibration.ece_delta` | с базовым прогоном: CI дельты ECE выше 0 — medium «калибровка ухудшилась»; ниже 0 — info «калибровка улучшилась» | medium / info |
| `comparison.disagreement` | с базовым прогоном, классификация: предсказанные классы различаются (порог 0,5 для бинарных вероятностей, argmax для multiclass) | info |

## Ожидаемое поведение

- B1. Дано: бинарные вероятности, систематически завышенные (ECE ≥ 0,1) · тогда `calibration.ece` medium «калибровка: ECE 0.… (10 корзин) — вероятности систематически расходятся с частотами»; факты `ece`, `bins`, `n`, `worst_bin` (например `0.8–0.9`), `worst_gap`; доказательства — id примеров худшей корзины (до 10, по id).
- B2. Дано: хорошо откалиброванные вероятности (ECE < 0,05) · тогда находки нет.
- B3. Дано: базовый прогон откалиброван, кандидат — нет · тогда `calibration.ece_delta` medium «калибровка ухудшилась: ECE <база> → <кандидат> (Δ +…, 95% CI [+…; +…])»; факты `baseline`, `candidate`, `delta`, `ci_low`, `ci_high`, `n`.
- B4. Дано: базовый и кандидат различаются в предсказанном классе на части примеров · тогда `comparison.disagreement` info «модели расходятся на <k> из <n> примеров (…%): кандидат прав в <a>, базовый — в <b>»; доказательства — до 10 id с наибольшей разницей вероятностей (при равенстве — по id).
- B5. Дано: сегмент из спецификации, значение которого занимает среди расхождений долю хотя бы на 15 п. п. больше, чем среди всех общих примеров · тогда к сообщению добавляется «; <доля>% из них — <сегмент>=<значение> (против <доля>% среди всех)», факты `segment`, `segment_value`, `segment_share`, `overall_share`.
- B6. Дано: модели не расходятся · тогда находки `comparison.disagreement` нет.

## Деградация и ошибки

- E1. Дано: выход не `probabilities` · тогда пропуск `calibration.ece`: «калибровка — только для output: probabilities».
- E2. Дано: регрессия или бинарные `scores` · тогда пропуск `comparison.disagreement`: «расхождение классов не определено для <тип · выход>».
- E3. Дано: у прогонов нет общих примеров или метки различаются · тогда пропуски с той же причиной, что у `comparison.metric_delta`.
