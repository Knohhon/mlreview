# Разброс по сидам и «улучшение в пределах шума»

Опора: FR-D05 (разброс по сидам и предупреждение «улучшение в пределах шума» — L1 · Must), B08 («улучшение» в пределах шума: разница меньше разброса по сидам), S02 («прогон с одним сидом — разброс по сидам не оценён»), S06 (сколько сидов нужно, чтобы различить эффект), NFR-05.

Модуль `mlreview.analyzers.seeds`, группа `metrics`. Прогоны стороны — основной и его сиды (`docs/specs/analyzers.md`). Метрика — основная метрика задачи (`docs/specs/metrics.md`), по всем предсказаниям каждого прогона.

## Статистика

- Для каждой стороны: значения метрики по сидам, среднее, σ (стандартное отклонение, `ddof=1`).
- Разница — среднее кандидата − среднее базового; «улучшение» — с учётом направления метрики.
- Значимость — t-тест Уэлча, α = 0,05. Если σ обеих сторон 0 — разница значима, если не 0, и незначима, если 0.
- Сколько сидов нужно на конфигурацию, чтобы различить эффект такого размера (α = 0,05, мощность 0,8): n = ⌈2·(1,96 + 0,84)²·σ²/Δ²⌉, где σ² — среднее дисперсий сторон; при Δ = 0 — «не различить».

## Проверки

| Проверка | Когда | severity |
| --- | --- | --- |
| `seeds.within_noise` | есть базовый прогон, у обеих сторон ≥ 2 сидов, разница незначима: улучшение — high; ухудшение — info | high / info |
| `seeds.significant` | то же, разница значима: ухудшение — high; улучшение — info | high / info |
| `seeds.not_evaluated` | есть базовый прогон, но у какой-то стороны 1 прогон | low |
| `seeds.spread` | нет базового прогона, у кандидата ≥ 2 сидов: разброс | info |

## Ожидаемое поведение

- B1. Дано: по 3 сида, средние различаются на долю σ (p ≥ 0,05), кандидат лучше · тогда `seeds.within_noise` high «улучшение в пределах шума по сидам: <метрика> <база> → <кандидат> (Δ …), σ по сидам …, p = … (Уэлч, 3 и 3 сида); для эффекта такого размера нужно ≈ N сидов на конфигурацию»; факты `metric`, `baseline_mean`, `candidate_mean`, `delta`, `baseline_std`, `candidate_std`, `p_value`, `baseline_seeds`, `candidate_seeds`, `seeds_needed`; предложение — не считать улучшение доказанным и повторить на N сидах.
- B2. Дано: по 3 сида, кандидат значимо лучше · тогда `seeds.significant` info «улучшение устойчиво по сидам: …»; значимо хуже — high «ухудшение устойчиво по сидам: …».
- B3. Дано: базовый прогон, у кандидата 1 прогон · тогда `seeds.not_evaluated` low «разброс по сидам не оценён: у кандидата 1 прогон, у базового 1 — интервал только по примерам; нужно хотя бы 3 сида на конфигурацию».
- B4. Дано: без базового прогона, 3 сида кандидата · тогда `seeds.spread` info «разброс по 3 сидам: <метрика> <среднее> ± <σ> (min …, max …)».
- B5. Дано: те же входы · тогда факты идентичны (NFR-05).

## Деградация и ошибки

- E1. Дано: без базового прогона и один прогон · тогда пропуск `seeds.spread`: «один прогон — разброс по сидам не оценён».
- E2. Дано: сиды одной стороны или стороны между собой оценены на разных данных (разный `data_hash`) · тогда пропуск «сиды оценены на разных данных: …»; находки сидов не строятся.
- E3. Дано: метрика не определена на каком-то сиде · тогда пропуск с id прогона.

## Вне рамок

- Поправка на множественные сравнения по нескольким датасетам (S06 — предложение), сиды внутри одного прогона MLflow (вложенные прогоны).
