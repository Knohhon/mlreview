## Claude

`conda activate` не сработает через `!`: такая команда идёт в отдельной неинтерактивной оболочке, где conda не инициализирована. Даже с инициализацией активация ничего не дала бы: окружение не переходит между командами, а хуки получают PATH от самого процесса Claude Code.

Есть два способа это исправить:

1. **Перезапустить Claude Code из нужного окружения.** Выйти и в обычном терминале выполнить:
   ```
   conda activate mlreview
   claude --continue
   ```
   Тогда хуки и все команды будут брать `python`, `ruff` и `pytest` из `mlreview`.

2. **Прописать окружение для проекта.** Я могу добавить в `.claude/settings.local.json` переменную `PATH` так, чтобы `/home/user/miniconda3/envs/mlreview/bin` шёл первым. Этот файл в `.gitignore`, поэтому путь, специфичный для вашей машины, в репозиторий не попадёт. После этого не придётся помнить про `conda activate`, но изменение вступит в силу только после перезапуска Claude Code.
